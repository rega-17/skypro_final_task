Git

  • git unit-эта команда создает новый репозиторий Git в текущем каталоге.
  • git clone-клонирует существующий репозиторий из удаленного источника на локальный компьютер.
  • git add.-добавляет все изменения в индекс, подготавливая их к коммиту.
  • git commit-фиксирует изменения, добавленные в индекс, с комментарием.
  • git push-отправляет локальные коммиты в удаленный репозиторий/
